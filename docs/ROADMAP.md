# Roadmap

## KitKat baseline

- Reproduce a clean build and test a freshly written SD image.
- Package a release with checksums, source revisions and hardware test notes.
- Validate Wi-Fi reconnection, USB hotplug and sustained memory/CPU load.
- Improve external-power reporting and investigate graphics acceleration.
- Bring up audio and Bluetooth where practical.

## Interface exploration

- Explore a coherent green-accent design compatible with Holo conventions.
- Prototype a custom launcher, notification shade and system interaction model.

## Android 2.3.7 experiment

- Create an isolated device configuration and compatible build environment.
- Validate userspace/kernel ABI, init, graphics and USB input before Wi-Fi.
- Preserve the working KitKat baseline throughout development.

Gingerbread has not been ported. No dates or guaranteed speedups are promised.
