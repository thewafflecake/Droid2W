# Droid2W

Проект портирования Android на Raspberry Pi Zero 2 W.

Текущая основа — Android 4.4.4: на реальной плате проверены загрузка Android,
вывод через HDMI, USB ADB, Wi-Fi и ADB по сети. Работа USB-клавиатуры/мыши
в режиме host подтверждена владельцем платы. Интерфейс 320×480 проверен на
установленной системе; физический HDMI остаётся 1280×720.

Репозиторий содержит настройки платы, скрипты адаптации и сборки. Полные
исходники AOSP и Linux, готовые образы, личные ключи и пароли сюда не включены.
Чистая сборка опубликованного набора пока отдельно не испытана на плате.

Экспериментальные образы для microSD публикуются в
[Releases](https://github.com/thewafflecake/Droid2W/releases).
Для записи через Raspberry Pi Imager нужна карта от 4 ГБ; порядок установки
описан в [FLASHING.md](FLASHING.md). Статус проверки конкретного образа указан
в примечаниях к релизу.

Android 2.3.7 — планируемый эксперимент. Собственный интерфейс и дизайн
с зелёными акцентами — дальнейшее направление, пока без реализации.

Для USB-клавомыши нужен профиль host, для USB ADB — peripheral. Одновременная
работа достигается через Wi-Fi ADB и USB host. Питание подают через PWR IN.

Инструкции сборки и ограничения приведены в [BUILD.md](BUILD.md) и
[ARCHITECTURE.md](ARCHITECTURE.md).
