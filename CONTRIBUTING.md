# Contributing

Keep changes focused and describe what was tested on real hardware versus
only built or reviewed. Preserve third-party notices. Do not commit generated
binaries, firmware blobs, SD images, ADB keys, Wi-Fi credentials or private logs.

For hardware reports include the board, power supply, connected devices,
USB role, source revisions, expected result and actual result. Include only
the relevant sanitized log excerpt. A successful compilation is not proof of
a successful hardware boot.
